# 🛒 Baraz eCommerce

Baraz eCommerce is a modern full-stack eCommerce web application that allows users to browse products, manage their shopping cart, place orders, and securely authenticate. It is built with a scalable architecture using React, Node.js, Express, and MongoDB.

## 🚀 Live Demo

- Url: https://wondrous-biscuit-27b2a1.netlify.app/

## ✨ Features

- 🔐 User Authentication (Login/Register)
- 👤 User Profile Management
- 🛍️ Product Listing & Details
- 🔍 Product Search & Filtering
- ❤️ Wishlist
- 🛒 Shopping Cart
- 💳 Checkout System
- 📦 Order Management
- 📱 Fully Responsive Design
- 🌙 Dark Mode/ Light Mode

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/shimonmondol/Full-Stack-Ecommerce
```

```bash
cd baraz-ecommerce
```

### Install Frontend

```bash
cd client
npm install
npm start 
```

### Install Backend

```bash
cd server
npm install
npm run dev
```

## 🔑 Environment Variables

Create a `.env` file inside the server directory.

```env
PORT=5000

MONGODB_URI=your_database_url

JWT_SECRET=your_secret_key

CLIENT_URL=http://localhost:5173
``
